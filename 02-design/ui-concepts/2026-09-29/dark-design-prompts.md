# Sycamore — three additional dark UI concepts

Created September 29, 2026 with the built-in imagegen tool. These are visual proposals; no website code was written or changed. Sample reporting, timestamps, geographic imagery, and controls are illustrative.

## Concepts

- [Horizon](04-horizon.png): panoramic Earth canvas, horizontal reporting tray, obsidian and steel-blue palette. Recommended for the most striking spatial overview.
- [Nocturne Desk](05-nocturne-desk.png): dark editorial Threat desk, asymmetric story hierarchy, midnight plum and copper palette.
- [Obsidian Index](06-obsidian-index.png): full-width reporting index, inline source details, quiet cartographic globe, carbon and celadon palette.

All three intentionally change composition and visual identity from the first set. Source actions, approximate-location labels, data health, and illustrative-data disclosures stay visible.
