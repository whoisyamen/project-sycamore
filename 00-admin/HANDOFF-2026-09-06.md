## What changed
1. Flights as airplanes: `src/client/globe.ts` uses
   `BillboardCollection` (not PointPrimitive) with
   `public/data/globe/plane.svg` (white top-down airliner, nose-up).
   Rotation from flight `hdg` via `Cesium.Math.toRadians`, 11x11 px,
   `PLANE.withAlpha(0.7)`, `scaleByDistance(2e5,1.0,1.9e7,0.55)`.
   Trails 1.4px at 0.3 alpha. Keeps `primitives.get(2).length===1`.
2. Investigation palette: INK #0b0b0c, PLANE #a8a5a0, BRASS #c99a3f,
   BLOOD #c4453c, SLATE #8a8d90, ASH #6e6e6e. CSS tokens
   --bg #0b0b0c, --surface #131315, --text #e8e6e1, --accent #c99a3f.
   Critical=BLOOD, escalating=BRASS, watching=SLATE, deesc=ASH.
3. Oceans: flat 1px #08111f `SingleTileImageryProvider` tile (zero
   external traffic by default), `scene.globe.baseColor=OCEAN`,
   permanent continent outlines in separate `borders` CustomDataSource
   (steel 55%). Esri satellite toggle unchanged.
4. Censys migration: code-complete on ingest + client. Leftovers only:
   `00-admin/DECISIONS.md:170` reworded to Censys, `_private/runtime.env`
   is a template with empty CENSYS_PERSONAL_ACCESS_TOKEN /
   CENSYS_ORGANIZATION_ID, stale shodan .pyc removed. Remaining
   "shodan" mentions intentional (negative test, README note, archive).
5. Map outage + fix: SingleTile without tileWidth/tileHeight threw
   `Expected options.tileWidth...`, killing globe construction and
   showing "Map unavailable". Fixed at globe.ts:203 with
   `tileWidth: 1, tileHeight: 1`. Diagnostic error-surfacing hook in
   dashboard.ts was added then reverted.
